## Auto Log

Full-stack vehicle log app with a Spring Boot backend and an Angular frontend.

## Tech Stack
- Backend: Spring Boot 4 (Java 21), Spring Security, JPA, PostgreSQL
- Frontend: Angular 20

## Run Locally
### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
ng serve
```

## Notes
- Backend configuration lives in `backend/src/main/resources/application.yml`.
